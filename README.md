# HR Analytics Dashboard

An interactive **Power BI dashboard** project that visualizes key HR metrics to help organizations make data-driven decisions related to employee performance, attrition, job satisfaction, and more.

![Dashboard Preview](https://github.com/architaa1/HR_ANALYTICS_DASHBOARD/blob/main/HR_ANALYTICS_DASHBOARD_image.jpg) 

---

## 📌 Overview

This HR Analytics Dashboard is built to analyze employee data from various perspectives including:

- Attrition Rate
- Job Satisfaction
- Performance Ratings
- Monthly Income
- Department-wise insights
- Demographic trends (Age, Gender, Education)

The insights help HR departments in identifying problem areas, improving employee retention, and boosting overall organizational productivity.

## 📊 Key Features

- Clean and user-friendly UI
- Filters and slicers for interactivity (e.g., Department, Education, Gender)
- KPIs displayed on top: Active Employees, Attrition Rate, Avg. Monthly Income, etc.
- Drill-down functionality for department-wise and job role-wise analysis

---

## 📈 Sample Insights

- **Higher Attrition** among employees in Sales and Human Resources
- **Job Satisfaction** varies widely between departments
- **Younger Employees** tend to have higher attrition rates
- **Monthly Income** increases with performance and education

## 🚀 Getting Started

1. Download or clone the repository.
2. Open the `.pbix` file in Power BI Desktop.
3. Explore the dashboard and interact with the filters and visuals.
